# Remaining Family Closure Matrix

This matrix turns every requested family into an auditable implementation
program. “Registered” and “in progress” do not mean production-complete.

| Family | Current evidence | Remaining closure gates |
|---|---|---|
| Memory and cognition | Identity-scoped associative graph, decay, reinforcement, consolidation, prediction, belief categories, workspace and introspection are unit-tested | Crash-safe persistence, perception/language integration, contradiction handling, regulated affect, learning benchmarks, fuzzing and end-to-end cognition tests |
| Development and independence | Competency maturity vectors are unit-tested; teaching/inheritance separation is specified | Embryology orchestration, curricula, sleep, maintenance, play, guardian policy, independence simulations and regression benchmarks |
| Models, senses and embodiment | Adapter/capability/platform schemas exist | Local-model discovery, multimodal ABI implementations, body/avatar simulation, hardware interlocks, observed device evidence and per-route qualification |
| Networking and distributed cognition | Network identity and shared-domain boundaries are registered | Authenticated protocol, partition/recovery tests, specialist-agent contracts, private/shared reconciliation and distributed replay evidence |
| Security and platform qualification | Owner-bound threat/policy/provider qualification, exact route binding, secret-free key metadata, typed-use/cryptoperiod/lifecycle gates, rotation/recovery lineage, immutable evidence recovery, external-reference baseline, provenance, immune boundary and secret scan exist; all are evidence/control layers | Select and independently verify a real provider/KSP/module/environment; implement native key generation/open/use/deletion, authentication and authorization, authenticated migration/recovery, fuzzing, sanitizers, coverage thresholds, external review and named platform/device qualification |
| Descendants and evolution | Lineage, deterministic reproduction, birth snapshot and mutation audits are tested | Population policy, fitness observation, diversity metrics, containment, long-horizon experiments and hard prevention of uncontrolled self-replication |

No hardware, network, cryptographic, distributed, or autonomous reproduction
route may advance from declared to qualified without observed evidence for the
specific model, device, operating system, connection, and failure mode.
